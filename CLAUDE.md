# CLAUDE.md

## Agent skills

### Issue tracker

Public GitHub Issues (`gh` CLI) for intake and triage; specs, tickets and wayfinder maps stay private as local markdown in the gitignored `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

The five triage roles map to labels written with spaces: `needs triage`, `needs info`, `ready for agent`, `ready for human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
